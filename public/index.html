Project Description

Lingodeck is a native Android app designed to make language learning efficient and permanent. Built with Kotlin and Jetpack Compose, it uses a Spaced Repetition System (SRS) algorithm to schedule flashcard reviews at the optimal moment, just before a user is likely to forget a word. This way users can maximize their retention while not wasting study time.

App Concept

1. Use Case

Efficient Vocabulary Acquisition:
The primary use case is daily vocabulary study for language learners. Instead of reviewing static lists or paper flashcards (which leads to over-studying known words and under-studying difficult ones), the user opens Lingodeck once a day. The app automatically presents only the specific cards that are "due" based on the user's past performance, handling the complex scheduling logic in the background.

2. Target User

  • Language Learners: Anyone learning a new language who wants to optimize their vocab studying.

User Flow Diagram

High Fidelity Prototype

Screen Breakdown:

  1. Deck List (Home): The entry point where users manage different languages (e.g., German, Spanish).
  2. Deck Detail (Dashboard): A view showing the "Upcoming Reviews" bar chart and a list of all cards. This allows the user to see their workload for the week.
  3. Study Mode (The Core Loop): The clean interface where cards are presented. Users interact via gestures (swiping) to grade their memory retention, which immediately updates the database schedule.

4. Data Model

The app persists data locally using Room Database. The core entities are Decks, Flashcards, and Study Sessions.

5. Usability Test

Usability Test Plan

  • Heuristic Evaluation: Conducted using Nielsen's 10 Usability Heuristics to identify initial issues (e.g., lack of system status visibility, confusing navigation).
  • Hypothesis: Users will struggle with gesture discoverability (H1) and understanding the "Start Review" interaction model (H5) but will find the completion screen motivating (H9).
  • Planned Data to Collect:
    • Task Success Rate: Can users complete the review session?
    • Error Rate: Frequency of mis-swipes or incorrect clicks.
    • Subjective Metrics: SEQ (Single Ease Question) scores and SUS (System Usability Scale) feedback.
  • Methods Used: Moderated in-person testing with a "Think Aloud" protocol.
    • Tasks: 1. Start a learning session, 2. Review flashcards, 3. Monitor progress, 4. Interpret feedback.
    • Materials: Pre-test questionnaire, Post-task SEQ, Post-test SUS, and interview questions.

User Test Results

  • Participants: 5 test subjects (Age range: 18-36). Mixed experience with language learning apps; no prior experience with LingoDeck.
  • Quantitative Evaluation Summary:

    Metric Average Score Interpretation
    Task Success Rate 100% All users completed the core loop, though some needed minor guidance.
    SEQ (Ease of Use) 5.8 / 7 Tasks were generally perceived as easy once the initial gesture was learned.
    Swipe Error Rate Low (< 10%) Users quickly adapted to the swipe mechanics after the first card.
  • Relevant Feedback / Comments:
    • "I didn't know I had to swipe at first, I tried tapping the buttons." – (P1, P3)
    • "The 'Practice' button is blue, which is nice, but I thought it was the main action initially." – (P2)
    • "I love the confetti at the end, it makes me feel accomplished." – (P5)
  • Updates Based on Feedback:
    • Swipe Hints: Added visual cues (rotation animations) during card swipes to better indicate interactivity.
    • Button Hierarchy: Adjusted the 'Practice' button color to AccentBlue to differentiate it from the primary 'Review' action while maintaining visibility.
    • Anki Import: Enhanced the import flow to allow language selection, improving the TTS experience for imported decks.
